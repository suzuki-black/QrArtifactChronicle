QRコードを読み込むと、その情報（特に生成日時）をもとに架空の古代文明の遺物を
決定論的に生成・収集するアプリの設計一式です。

## 用語の注意（重要）

仕様書には「時代」という語が2つの異なる意味で登場します。本設計では明確に区別します。

- **遺物時代 (artifact-era)**: 古代/中世/近世/近代/未来 など。架空属性で、**ハッシュから決定**。
- **QR年代 (qr-decade)**: 2020年代/2010年代… という**現実世界の年代**。QRの生成日時から算出し、
  **時代補正値**の根拠になる。

この2つは無関係です。混同するとレア度計算が破綻するため、コード・DBともに別名で扱います。
